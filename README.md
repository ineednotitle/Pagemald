# PageMeld 1.3.19 — ineednotitle custom build

This is the single install-ready GitHub Release asset for PageMeld 1.3.19. The archive contains `main.js`, `manifest.json`, and `styles.css` at its root, plus this README and the required third-party license notices.

## Compatibility

The Obsidian plugin ID intentionally remains `make-md`, so the existing plugin folder, data.json settings, and internal integrations continue to work. The displayed plugin name is PageMeld.

## Install

1. Back up `.obsidian/plugins/make-md` and keep the existing `data.json`.
2. Extract the archive contents into `.obsidian/plugins/make-md/`, replacing `main.js`, `manifest.json`, and `styles.css`.
3. Reload Obsidian. The desktop toolbar remains off by default; enable it in **Settings → PageMeld → Notion-style block editing → Editing Toolbar** if desired.

This release rebrands the existing plugin and preserves the 1.3.18 runtime optimizations and page-switching title fix. No live Obsidian desktop/mobile test was performed. Existing community/documentation service links are retained until replacement PageMeld URLs are provided.
